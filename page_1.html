台本 0430秒リール台本 3パターン — 概要

以下の3パターンはすべて約150〜180文字（30秒尺）で設計しています。 1カット約3〜4秒を目安に、テロップを画面に重ねて視覚と音声を二重化することで完視聴率を最大化します。

パターン構成法特徴・向いているケース
Pattern 1 PREP法 結論先出しで論理的に納得させる。「なぜ？」を自然に解消できるため教育系に最適
Pattern 2 PASONA法 悩みから始まり解決策で終わる感情導線。共感・不安→希望の流れでDMシェアを誘発
Pattern 3 フック型 冒頭の衝撃で全視聴を強制。最速で行動させたい時・新規リーチ最大化に最適
Pattern 1 / PREP構成
「AIで副業月5万は3ステップで実現できる」
Point（結論）→ Reason（理由）→ Example（具体例）→ Point（再結論＋CTA）
論理的説得力が高く、保存・DM共有を誘発しやすい構成。教育系アカウント向け。
Hook / Point 0〜3秒
「AIを使えば、スキルゼロの30代でも副業で月5万を3ステップで出せます。」

演出メモ：「スキルゼロ / 30代 / 月5万 / 3ステップ」を大きく表示。ターゲット指定＋数字提示の複合フック。

Reason 3〜12秒
「なぜなら今のAIは、コンテンツ作成・投稿・DM返信を自動化できるから。」
「以前は1投稿に3時間かかっていた作業が、今は15分で終わります。」

演出メモ：3秒ごとにカット切り替え。「自動化」「15分」などテロップ強調。

Example 12〜24秒
「ステップ1：ChatGPTで台本を作る。ステップ2：AIで画像生成。ステップ3：自動スケジュール投稿。」
「この3つで、毎月60本の投稿を半自動で回せるようになります。」

演出メモ：箇条書き風テロップでステップを視覚化。テンポよく1ステップ約2秒。

Point（再結論）+ CTA 24〜30秒
「副業はスキルじゃなく、AIの使い方で決まります。詳しくはプロフから。保存しておいてね。」

演出メモ：「保存」ワードで保存数を誘導。「プロフから」でプロフ訪問数を増やしアルゴリズムに加点。

制作・演出メモ
  • 冒頭は自分の顔アップ or 数字を書いたホワイトボードから始めるとCTR向上
  • BGMはテンション高めのトレンド曲（ビートに合わせてカット）
  • テロップカラー：白文字＋黒縁取り、数字だけ黄色で強調
  • 「3ステップ」は画面下にステップインジケーターとして常時表示するとリテンション向上
Pattern 2 / PASONA構成
「副業で稼げない人がやっている、たった1つの間違い」
Problem（問題）→ Affinity（共感）→ Solution（解決策）→ Offer（提案）→ Narrow（絞込）→ Action（行動）
感情の波を作り「自分ごと化」させる。悩みを抱えたターゲットへの訴求力が最大。
Problem + Hook 0〜4秒
「副業を始めたのに3ヶ月で諦めた人、実は全員同じミスをしています。」

演出メモ：ショック型フック。「諦めた人」「同じミス」で共感＋不安を同時喚起。

Affinity（共感） 4〜10秒
「時間がない、スキルがない、続けられない——わかります。私も1年間そこで止まっていました。」

演出メモ：ターゲットの「あるある」を言語化。感情的な共鳴を作るパート。少しテンポを落として共感を深める。

Solution（解決策） 10〜20秒
「そのミスは、『手作業でやろうとしていた』こと。答えはAIに全部任せること。」
「ChatGPTで台本、Canva AIで画像、Metaスケジューラーで投稿。全部自動化できます。」

演出メモ：ミスの正体を「一言」で断言。その後に解決ツール3つを高速で畳み掛ける。

Offer + Narrow（絞込） 20〜26秒
「これ、本気でAI副業を始めたい30〜40代の人にしか教えたくない情報です。」

演出メモ：「絞り込み」で希少性と特別感を演出。ターゲット外を意図的に切ることでターゲットの没入感が上がる。

Action（行動） 26〜30秒
「詳しい手順はプロフのリンクで無料公開中。まず保存して後で読んでください。」

演出メモ：「無料」「保存」「後で」3ワードで行動ハードルを最低化。DMシェアを誘発する共感型CTA。

制作・演出メモ
  • 冒頭「副業を始めたのに」のセリフ中に顔をやや俯かせると共感演出になる
  • Affinity部分はBGMを少し下げ、Solution部分でBGMを上げて「転換感」を演出
  • 「全員同じミス」「全部自動化」のキーワードはテロップを赤と白で交互に強調
  • 「30〜40代」テキストを画面に大きく出すとターゲット自己認識を強化
Pattern 3 / フック型
「知らないと5年後に後悔する、AIで稼ぐ人と稼げない人の差」
強烈フック → 高速バリュー提供 → 強制保存CTA
最初の2秒で全視聴を確定させ、最短でフォロー・保存・DM共有を引き出す。新規リーチ最大化に最適。
SUPER HOOK 0〜2秒
「知らないと5年後に後悔します。AIで稼げる人と稼げない人、差はたった1つだけです。」

演出メモ：警告型＋数字型の複合フック。「1つだけ」で「答えを知りたい」という好奇心を最大化。断言口調で信頼感を演出。

高速バリュー 2〜22秒
「稼げない人：自分で作る。稼げる人：AIに作らせる。」
「稼げない人：毎日投稿で消耗。稼げる人：週1作業で30本を自動投稿。」
「稼げない人：センスがないと無理と思ってる。稼げる人：センスはAIが補うと知ってる。」

演出メモ：「稼げない人 vs 稼げる人」の対比構成。3連打でリズム感を作り、テロップでビジュアル的に左右対比させると完視聴率が上がる。各行2〜3秒でテンポ良く。

強制保存CTA 22〜30秒
「どっちになるかは今の選択次第。この動画、絶対に保存しておいてください。続きはプロフから。」

演出メモ：「絶対に」の強調で保存を強制。「どっちになるか」で視聴者に選択を迫り、自己決定感を促す。プロフ誘導でフォロー率向上。

制作・演出メモ
  • 冒頭はカメラに向かって指差しアクションから始めると停止率が大きく上がる
  • 「稼げない人」と「稼げる人」は画面を左右に2分割するテロップレイアウトで視覚対比を作る
  • BGMは最初から最後まで高テンションを維持。音楽のビートに合わせてカットを切る
  • 「保存」のCTA時にテロップを点滅させると保存数が伸びる傾向あり
  • 最もDMシェアを誘発しやすいパターン。「これ友達に送りたい」と思わせる余白を意識する
